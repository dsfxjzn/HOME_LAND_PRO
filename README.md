# HOME LAND PRO — سورس وطن

سورس جديد لإدارة كروبات تيليگرام على Ubuntu 24.04 / Lua 5.4.

الحقوق: المطور `@FFF70F` — القناة `@Bb_1_p`.

## الميزات
- لوحة تفاعلية `/panel` بأزرار للحماية والترحيب والإحصائيات والألعاب
- `/start`, `/help`, `/id`, `/ping`, `/stats`
- إدارة بالرد: `/ban`, `/kick`, `/mute 10`, `/unmute`
- إنذارات `/warn`, `/warnings`, `/clearwarn`؛ 3 إنذارات تحاول كتم العضو 10 دقائق
- منع روابط `/antilink on|off` ومكافحة تكرار `/antispam on|off`
- ترحيب `/welcome نص` مع `{name}` ومغادرة `/goodbye on|off`
- ردود مخصصة `/custom كلمة | رد` و`/delcustom كلمة`
- رتب `/rank` بالرد مع `مدير|مميز|موثوق|عادي`
- ألعاب `/coin`, `/dice`، وحفظ إعدادات JSON محلياً
- لا يوجد إرسال بيانات لخدمات خارج Telegram Bot API

## تنصيب
خذ نسخة احتياطية من `/opt/homeland/data.json` و`/etc/homeland.env` قبل التحديث. لا تحذف النسخة القديمة `/root/HoMeLaNd`.
من مجلد المشروع شغّل `sudo bash install.sh`.
يجب أن يحتوي `/etc/homeland.env` على:
```
BOT_TOKEN=YOUR_NEW_TOKEN
DATA_FILE=/opt/homeland/data.json
```
ثم `chmod 600 /etc/homeland.env`، وبعد المراجعة `systemctl restart homeland`.
لا ترفع ملف env أو التوكن إلى GitHub. اجعل المستودع Private، لأن توكن البوت ظهر سابقاً في لقطة شاشة ويجب إلغاؤه من BotFather واستبداله.
اختبر في كروب تجريبي، واجعل البوت مشرفاً بصلاحيات حذف الرسائل وحظر/تقييد الأعضاء.

## حدود النسخة
مكافحة السبام بسيطة وليست نظاماً متقدماً. الرتب المحلية لا تستبدل صلاحيات تيليگرام الرسمية. إحصائيات النسخة الجديدة تبدأ من وقت استخدامها ولا تستورد تاريخاً غير موجود.
